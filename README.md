研究で使えそうな問い
ゲームセンター全体の店舗数は減少している一方で、クレーンゲーム・プライズゲームは売上の中心になっている。なぜクレーンゲームだけが伸びているのかを、以下の視点から分析する。
・景品、アニメ、IPコンテンツによる集客
・SNSでの拡散性
・低価格で遊べる体験価値
・インバウンド需要
・コンビニや商業施設への進出
・データ分析による景品配置、客単価、回転率の最適化
・USJなどの成功事例に見られる「体験価値」との共通点
